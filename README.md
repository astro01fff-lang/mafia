# Мафия

Классическая мафия онлайн до 20 игроков. Один файл `index.html`, без сервера и регистрации.

Как играть:
1. Ведущий открывает сайт, нажимает «Я ведущий» → «Создать комнату» и отправляет приглашение в общий чат.
2. Игроки открывают ссылку, вводят код комнаты и своё имя.
3. Ведущий нажимает «Раздать роли и начать». Вкладку ведущего держите открытой всю игру.

Для пробной партии в комнате есть кнопки «Добавить 5 ботов» и «Заполнить до 20».
